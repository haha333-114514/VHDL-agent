## 为什么用这七个实验概括

数据类型用极值跨界揭露问题；结构生成用局部正确、末级截断解释位宽；文件操作与测试平台合并成实际文件回归；PLD 抽象分别用 LUT、RAM 和寄存数据通路承接；设计优化通过流水和迭代体现空间 / 时间安排。

已有计数器与状态机继续覆盖优先级、时钟边沿和状态重叠；FIR 连接历史样本、信号更新与算法电路。每个新增实验引入不同的核心误区。

## 在应用中使用

1. 进入“实验工作台”，点击“课程扩展 7”。
2. 选择实验，查看规格、标题映射和验证限制。
3. 运行“检查并诊断”，查看真实反例与提示。
4. 点击“验证资料”，检查本次测试平台和源码。
5. 对 ROM 实验，切换文件输入和输出，核对实际 textio 行为。
6. 修改重跑或独立验证参考实现，再回答两道理解问题。

## 不能仅凭标题补出的内容

具体芯片型号、LUT / 宏单元组织、I/O 电压标准、PLL 参数、RAM 碰撞规则、上电初始化能力和目标器件时序，不能从这些标题直接确定。

本次提供明确约定的功能模型。通过测试不代表已经匹配某款 Lattice 原语，也不代表综合、布局布线、Fmax 或板级结果。继续研究器件级内容需要对应型号、手册与工具工程。
