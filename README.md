# 知电 · 数字电路学习智能体

**从一个反例，理解一段电路。**

一个可在 Windows 本机运行的教学原型：固定任务规格 → GHDL 真实编译与仿真 → 独立参考值对照 → 分层提示 → 修改后复测 → 变式问题 → 本地学习记录。

## 快速启动

本项目使用 Python 标准库，没有 pip、Node 或前端构建依赖。

1. 安装 **Python 3.10+** 与 **GHDL**，使 `python --version`、`ghdl --version` 可以运行。
2. 双击项目根目录的 **启动知电.bat**，或在此目录执行：

   ```powershell
   python server.py
   ```

3. 浏览器打开 `http://127.0.0.1:8765`。关闭运行终端或按 Ctrl+C 停止服务。

当前开发机器已检测到 Python 3.10 和 GHDL 6.0.0。若其他机器未将 GHDL 加入 PATH，复制 `.env.example` 为 `.env`，设置 `GHDL_PATH` 为 ghdl 可执行文件的绝对路径，例如：

```text
GHDL_PATH=C:/msys64/ucrt64/bin/ghdl.exe
```

端口占用时执行 `python server.py --port 8766`。不自动打开浏览器时加 `--no-browser`。

v0.4 加固真实仿真的判定：未知电平不能按 0 通过，检查点必须与固定清单逐项一致，仿真超限不算完成。新增每轮实际模型、用量与服务报告费用记录；最终解释只展示模型最后一轮回复。实测与边界见 [v0.4 验证与改进](docs/v0.4验证与改进.md)。

## 两种运行方式

### 本地证据诊断（默认）

无需密钥、无需网络。按固定教学工作流执行 GHDL，并根据实际编译信息或失败用例提供规则诊断。此模式**没有调用大语言模型**；提示与参考实现来自内置教学内容。

### 模型智能体（可选）

点击“模型设置”，选择 **OpenRouter · 免费模型** 预设，在 [OpenRouter](https://openrouter.ai/keys) 注册并申请 API Key，填入后保存。预设使用 `https://openrouter.ai/api/v1`、`openrouter/free` 和 Chat Completions 协议。无需 OpenAI / Codex API 密钥。

根据 [OpenRouter 免费路由说明](https://openrouter.ai/docs/guides/routing/routers/free-router)，此路由仅选择免费模型，并按请求筛选工具调用能力；实际模型会显示在模型诊断中。免费额度、模型供应和响应速度由平台控制，一次实验可能多轮请求，不等于一次 API 调用。遇到限流时保留本地仿真结果，不自动重试或切换付费模型。额度以[账户与平台说明](https://openrouter.ai/docs/api/reference/limits)为准。

保存只检查配置格式，是否可用以实际运行返回为准。网页输入的密钥仅留在服务进程内存，重启后失效。选择计数器错误示例，切换“模型智能体 · 工具调用”，提问“请读取任务约束和失败波形，提出最小修改并调用工具验证”，运行后检查执行轨迹中的模型请求和工具返回。只看到本地仿真结果不能证明云模型已接通。

也可以在 `.env` 中配置：

```text
MODEL_BASE_URL=https://openrouter.ai/api/v1
MODEL_NAME=openrouter/free
MODEL_API_KEY=填写你的OpenRouter密钥
MODEL_PROTOCOL=chat_completions
```

持久配置应保存为项目根目录的 `.env`，然后重启服务。不会自动读取其他项目的密钥。原有 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL` 仍兼容；存在任意 `MODEL_*` 配置时，改用这一组配置，不沿用旧密钥到新地址。

也可选择“自定义服务”：支持提供函数调用的 Chat Completions 兼容接口，或设置 `MODEL_PROTOCOL=responses` 使用 Responses API。不同平台的密钥不通用，接口兼容不代表模型免费，需确认平台的免费模型、额度及工具调用支持。

模型实际可调用的五个工具：

| 工具 | 功能 |
| --- | --- |
| `inspect_contract` | 读取当前固定任务规格和接口 |
| `run_simulation` | 自主选择基础、边界或完整测试集 |
| `read_waveform` | 读取检查点附近的实际采样与参考值 |
| `read_learning_memory` | 读取本机概念练习与运行统计 |
| `propose_patch` | 在独立目录运行公开测试与两组新种子复核，不更改学生编辑器与规格 |

每次最多 6 轮模型规划，必要时增加 1 轮不能执行工具的结果归纳，共不超过 7 次模型请求、8 次工具调用；单次请求超时 45 秒。模型失败时，已完成的本地仿真结果仍保留。模型解释属于模型输出，最终通过状态始终取自实际 GHDL 结果。

实现依据：[OpenRouter 工具调用文档](https://openrouter.ai/docs/guides/features/tool-calling)和 [OpenAI 官方 function calling 文档](https://developers.openai.com/api/docs/guides/function-calling)。本机未配置模型密钥时，真实云模型调用不可验证；测试使用明确标注的模拟传输验证协议与工具编排。

2026-10-19 已完成一次免费云模型真实联调：计数器实验经 3 轮模型请求和 3 次工具调用，候选修复通过全部 103 个 GHDL 检查点。详细证据见 [免费模型联调记录](docs/免费模型联调记录.md)。这只证明该次流程通过，不代表所有模型或实验的效果。提交源码包不携带密钥，使用者需要自行配置。

## 数据与运行边界

- 服务只监听 `127.0.0.1`，面向个人本地使用，没有多人身份与权限系统。
- 默认本机记录位于 `data/learning.sqlite3`，每次运行产物位于 `data/runs/<实验编号>/`。源码草稿另保存在当前浏览器的 localStorage。
- 本地模式不联网；模型模式会把当前代码、问题与仿真摘要发送到用户配置的接口。模型选择读取学习记忆时，也会将对应概念统计发送到该接口。
- 支持 11 组固定接口的单文件电路。不能将任意多文件课程工程直接当作已支持项目，也不会自动读取你的旧作业目录。对应 PPT 正文未读取，新增知识点映射依据标题推测。
- 源码最多 40 KB，GHDL 单阶段限时 15 秒，日志与 VCD 有大小限制。禁止文件 I/O、foreign 绑定、自定义包 / 配置与测试平台保留标识符；工具不接受任意 shell。
- **工作目录与静态检查不是操作系统安全沙箱。仅在本机运行自己信任的教学代码，不适合公开托管后执行陌生人代码。**
- 采样图显示测试平台检查点，完整事件波形以 VCD 为准。仿真通过不包含形式化证明、综合、时序收敛或板级测试。
- 内置参考代码通过不计为学生独立通过；“非参考运行”也不能证明代码独立原创或学生已经掌握。

## 验证与打包

```powershell
python -m unittest discover -s tests -v
node --check web/app.js
python tools/evaluate.py
python tools/audit_grading.py --label current
python tools/evaluate_innovations.py
python tools/package.py
```

Node 仅用于可选的 JavaScript 语法检查，运行应用本身不需要它。测试缺少 GHDL 时会明确跳过仿真集成检查，不能将跳过视为已经验证。

评估脚本在 `data/evaluation/` 保存真实结果、源码哈希和完整日志。这是固定教学集的工程回归，不能宣称为模型泛化能力、自动修复成功率或学生学习效果实验。

打包输出：`dist/zhidian-v0.4-source.zip`。排除 `.env`、学习数据和运行产物；包含 `.env.example`、源码、说明与演示资料。GHDL / Python 需要在评审机器单独安装。

## 创新实验与重放

模型提交候选修改后，程序才生成两组新种子，补充随机输入、较大合法整数及新的时序序列；种子与测试平台 SHA-256 随报告保存。相同种子重建相同输入序列；每次仿真另有新日志标记，所以测试平台字节和哈希会改变。原样重放应使用保存的测试平台、输入文件和 checks.json。公开用例通过、额外验证失败时，程序拒绝把修改标为已验证。表决器、LUT、ROM 的有限输入已穷举，追加验证只改变输入顺序，不把它说成新的真值表输入。

实测 15 个受控功能故障：基础检查检出 1/15，公开完整测试检出 14/15，追加验证检出 15/15；11 个正确参考实现通过追加验证，共 1301 个检查点。一个故意迎合公开输入范围的 FIR 特判版本，通过公开测试但被追加验证拒绝。结果只针对这组受控工程实验，不等于通用模型修复率或教学提升。

```powershell
python tools/evaluate_innovations.py
```

这个命令调用真实 GHDL，不消耗模型 API 额度。记录见 [创新实验结果](docs/创新实验结果.md)及同名 JSON。
