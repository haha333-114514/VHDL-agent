      知电，如何帮助理解？

      以规格为起点，以仿真为证据，以理解为目标。

      01 / 背景

      “能编译”之后，才是理解的开始。

      数字电路初学者常遇到优先级、状态重叠与信号更新等问题。仅看代码，很难判断误差来自逻辑、时序还是采样约定。

      知电把固定规格、独立参考模型、真实 GHDL 工具和教学反馈连接起来，让每条建议都能回到具体反例。

      02 / 工作流程

      观察 → 检查 → 解释 → 再验证

      本地证据模式按固定流程执行基础检查与完整测试，依据真实失败用例给出规则诊断。

      配置模型后，模型可自主选择读取约束、补测、查看采样和验证候选修改。工具调用与结果在界面中可见，候选代码需要独立仿真。

      03 / 操作指南

      第一次使用，四步即可。

      1. 选择实验，阅读约束，先预测代码的行为。
      2. 运行“检查并诊断”，查看失败检查点与日志。
      3. 逐级展开提示，修改代码并重新检查。
      4. 回答变式问题，导出带源码和原始证据的报告。
      04 / 验证范围

      清楚记录，才能准确判断。

      本原型支持11 组固定接口的单电路教学任务，使用 VHDL-2008。当前结果仅代表测试集覆盖，不包含形式化证明、器件综合、布局布线或板级测试。

      本地诊断不联网。模型模式将当前代码、问题和仿真摘要发送至你配置的接口，按需读取概念练习统计。学习记录与运行产物保存在本项目 data 目录。

      05 / 创新验证

      修复要复测，测试也要被检验。

      模型提交候选修改后，程序再生成两组新种子。公开测试和追加验证全部通过，才能应用为“已验证的候选版本”。每组保留种子、测试平台指纹与真实波形，方便复查。

      2026 年 10 月 19 日的内置工程实验：15 个受控故障，基础检查检出 1 个，公开完整测试检出 14 个，追加验证检出 15 个；11 个正确参考实现全部通过。一个迎合公开输入范围的 FIR 特判版本，被追加验证拒绝。

      这些数字只属于这组受控实验，不代表通用修复率或学习提升。有限输入已穷举的任务，仅重排输入顺序。

      推荐演示

      普通计数正常，同时复位却出错。

      用计数器错误示例展示：基础检查通过 → 完整测试找到反例 → 观察分支优先级 → 修改并复测 → 回答同步复位变式题。

      连接模型智能体

      使用提供工具调用的模型服务，让模型读取反例、解释原因并验证候选修改。可先使用免费服务预设。

      免费预设使用 openrouter/free，由平台选择支持工具调用的免费模型。需申请 API Key；有额度和可用性限制，不会自动切换付费模型。

      模型模式会发送本题代码、问题、仿真摘要及按需读取的概念练习统计到此地址。更换地址时需重新填写密钥。本地证据模式不发送这些内容。此处配置重启后失效；持久配置可使用项目 .env 文件。
